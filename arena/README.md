# arena: every top ai in one tab, free

https://arena.ai - type one question, two different ais answer side by side. vote for the better answer and it reveals which models wrote them. that's how you find out which free ai is best for the stuff you actually ask.

## how to use it

1. open arena.ai
2. ask a real question (homework, essay outline, code bug)
3. read both answers, pick the better one
4. it shows you which ai wrote each
5. go use the winner on its own free tier

## which free ai for what

everything below has a free tier. when you hit the limit on one, switch.

| what you need | what i use |
|---|---|
| general stuff, homework, essays | https://chatgpt.com |
| google stuff, long files, drive docs | https://gemini.google.com |
| writing and code | https://claude.ai |
| research with sources linked | https://www.perplexity.ai |
| turn class notes into a study guide or podcast | https://notebooklm.google.com |

no promo codes, no paid plan needed for any of this.
