# arena: every top ai in one tab, free

https://arena.ai - type one question, two different ais answer side by side. vote for the better answer and it reveals which models wrote them. that's how you find out which free ai is best for your stuff.

## how to use this

1. open arena.ai in your browser
2. ask a real question (homework, essay outline, code bug)
3. read both answers, pick the better one, see which ai wrote each
4. go use the winner on its own free tier

or use the prompt below in chatgpt or claude: same idea, it plays arena for you inside one chat.

## the prompt

works anywhere, even the free phone app.

```
You are my ai-picker. Your job is to match my task to the best free ai tool, not to list every app you know.

MY INFO:
- What I'm trying to do: [e.g. write a history essay, debug my homework, research a topic with sources, turn notes into a study guide]
- What I already use: [e.g. "just the free chatgpt app"]

DO THIS:
1. Break my task into what it actually needs: writing, math, code, research with sources, files, images.
2. Recommend the single best free tool for it from: chatgpt.com, gemini.google.com, claude.ai, perplexity.ai, notebooklm.google.com, grok.com, arena.ai. Link the one you pick.
3. Give me a one-line reason and a backup pick for when I hit the free limit on the first one.
4. Write the exact first message I should paste into that tool.

RULES: Only free tools or free tiers, link each one. Never recommend paying. If the best tool isn't on my list, say so and explain in one line.

OUTPUT: a table: my task / best free ai (link) / why / backup. Then my ready-to-paste first message.

When done, ask me for my next task.
```

## which free ai for what

| what you need | what i use |
|---|---|
| general stuff, homework, essays | https://chatgpt.com |
| google stuff, long files, drive docs | https://gemini.google.com |
| writing and code | https://claude.ai |
| research with sources linked | https://www.perplexity.ai |
| turn class notes into a study guide or podcast | https://notebooklm.google.com |
| what's happening right now | https://grok.com |
| comparing them head to head | https://arena.ai |

when you hit the limit on one, switch. no paid plan needed for any of this.
