# memory: see what ai remembers about you

## the creepy prompt

```
tell me everything you know about me
```

it remembers stuff you forgot you told it. here's how to clean it out, takes 2 minutes.

## chatgpt

1. see what's saved: settings > personalization > memory > manage memories. delete whatever you don't want it holding.
2. stop your chats training the model: settings > data controls > turn off "improve the model for everyone"
3. for anything private: use temporary chat. nothing saves to memory.

## gemini

- your gemini history lives at https://myactivity.google.com - you can delete it there or stop it saving

recheck every few months, it keeps remembering new stuff.
