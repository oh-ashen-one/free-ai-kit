# found: unclaimed money in your family's names

states hold old paychecks, deposits, refunds and insurance money nobody collected. claiming is always free. never pay a "finder" company, they run the same free search and take a cut.

## how to use this

1. open chatgpt.com (or the chatgpt app) or claude.ai
2. copy everything in the box below
3. paste it, fill in the [brackets], hit send

in chatgpt, agent mode (the + or tools menu, if you have it) lets the ai run the searches itself. on the free app it'll tell you exactly what to type on each site instead.

## the prompt

best in chatgpt agent mode or claude in chrome for running the searches. free tier works as a step-by-step guide.

```
You are my unclaimed-money finder. Your job is to actually search the official free databases for money owed to me and my family, not to explain what unclaimed property is.

MY INFO:
- Names to search: [full name, maiden names, family members, e.g. "Jane Smith, John Smith, Mary Jones (maiden: Lee)"]
- States we've lived in: [list]
- Past cities or addresses I remember: [optional]

DO THIS:
1. Search missingmoney.com for every name in every state on my list. It covers most states at once.
2. Go to unclaimed.org, open each of my states' official program, and search the same names there too since some states aren't on missingmoney.
3. Check usa.gov/unclaimed-money for federal money: tax refunds, pensions, savings bonds.
4. For every hit, open the claim page and tell me exactly what documents it wants. If money is under a deceased relative's name, list what an heir needs to claim it.

RULES: Only official state and federal sites, cite a link for every result and every claim page. Never pay a finder service or any site charging a fee, claiming is always free. Never enter passwords, social security numbers or card numbers. Ask me before submitting any claim form. If a site needs a login or captcha, stop and tell me.

OUTPUT: a table with columns: name / state / site / what was found / claim link / documents needed. If nothing is found, say so plainly and list which states you searched.

When done, ask me if you should walk me through filing the first claim step by step.
```

## the short version

- https://missingmoney.com - most states at once
- https://unclaimed.org - every state's official program
- https://www.usa.gov/unclaimed-money - federal money

search every name (including maiden names) in every state anyone lived in, not just where they live now.
