# found: unclaimed money in your family's names

states hold old paychecks, deposits, refunds and insurance money nobody collected. claiming it is always free. never pay a "finder" company, they run the same free search and take a cut.

## the sites (official, free)

- https://missingmoney.com - searches most states at once, run with state officials
- https://unclaimed.org - links to every state's official program, covers the ones missingmoney skips
- https://www.usa.gov/unclaimed-money - federal money: tax refunds, pensions, savings bonds

## how i search

1. every name: full name, maiden names, common misspellings
2. every state anyone in the family lived in, not just where they live now. money gets stuck in the state it was left in
3. old addresses and apartments
4. deceased relatives: the family can often claim it. each state site lists what documents an heir needs
