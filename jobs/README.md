# jobs: let ai do the job hunt

paste these into chatgpt (chatgpt.com) or gemini (gemini.google.com), the free tier works. run them in order.

## step 1: find what you can actually apply to

```
here's my resume. list 20 job titles i'm qualified for that i might not think of, and the top 10 keywords recruiters filter for in each.
```

paste your whole resume under that line.

## step 2: tailor your resume per posting

```
here's a job posting. rewrite my resume so it matches this posting using only things that are true about me. keep it one page.
```

run this fresh for every posting, paste the posting in too. never let it invent experience, that's how you get caught in the interview.

## step 3: track it

```
make me a tracker table: company, role, link, date applied, follow-up date (7 days later), status.
```

put it in a google sheet. follow up when it says to, that's where interviews come from.
