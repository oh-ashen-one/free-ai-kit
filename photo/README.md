# photo: listing photos that don't look like a dorm room

upload your pic to chatgpt or gemini, paste a prompt. rule number one: never let it change the item itself. scratches and all. buyers trust it more and nobody returns anything.

## clean listing

```
put this exact item on a plain white background with soft studio lighting. do not change the item, keep every scratch, stain and detail exactly as it is.
```

## lifestyle

```
show this exact item sitting naturally on a wooden desk next to a lamp, soft daylight from a window. do not change the item at all, only the setting around it.
```

## detail shot

```
zoom in close on this exact item like a product detail photo, shallow depth of field, soft light. keep every scuff and detail visible, do not edit the item itself.
```

always post your real photo in the listing too. the ai one is the cover, the real one is the proof.
