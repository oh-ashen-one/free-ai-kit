# photo: listing photos that don't look like a dorm room

rule number one: never let it change the item itself. scratches and all. buyers trust it more and nobody returns anything.

## how to use this

1. open chatgpt.com (or the chatgpt app) or gemini.google.com
2. attach your photo of the item
3. paste a box below, hit send

works on free tiers. if it touches the item anyway, reply "don't change the item, redo it" and send again.

## clean listing

```
You are my listing photographer. Edit this photo for a marketplace listing: put this exact item on a plain white background with soft studio lighting, straight-on angle, true colors. Do not change the item itself, keep every scratch, stain, label and detail exactly as it is. If the edit would change how the item looks, stop and tell me instead.
```

## lifestyle

```
You are my listing photographer. Edit this photo so the exact same item sits naturally on a wooden desk next to a lamp, soft daylight from a window. Do not change the item at all, only the setting around it. Keep every scratch and detail visible. If the item would look different, stop and tell me.
```

## detail shot

```
You are my listing photographer. Edit this photo into a close-up product detail shot of the exact same item, shallow depth of field, soft light. Keep every scuff and detail visible, do not edit the item itself. If the item would look different, stop and tell me.
```

always post your real photo in the listing too. the ai one is the cover, the real one is the proof.
