# list: 5 things my ai does so i don't have to

the master prompt list. everything runs on free tiers.

## 1. calls and bookings i don't want to make

```
i need to book [thing] at [place] for [date, time, party size]. write the exact script i should say on the phone, plus a shorter version if they put me on hold. then list the 3 most likely questions they'll ask and my answers: [details].
```

## 2. bills

```
here's my [internet/phone] bill: [paste the charges]. find every fee and tell me which ones are negotiable or removable. then write what i should say when i call to get it lowered.
```

full guide in [bills](../bills/)

## 3. spam calls and my info online

```
walk me through opting out of the biggest data broker and people search sites, one at a time. i want my phone number and home address delisted.
```

the full opt out lists are in [calls](../calls/) and [erase](../erase/)

## 4. flips

```
here's my item: [name, condition]. what did it actually sell for recently, what should i list it at, and write the marketplace listing.
```

more in [sell](../sell/)

## 5. content

```
i make short videos about [your thing]. give me 10 hook ideas, then write a 45 second script for the best one: hook, proof, the trick, bonus, call to action.
```

pick one, run it today.
