# site: a real website for $0

two free tools: google ai studio builds the site, netlify drop puts it online.

## steps

1. go to https://aistudio.google.com and sign in with a google account
2. open build mode and type what you want in plain english
3. watch it build, then ask for changes: "make it darker", "add my tiktok link", "bigger name at the top"
4. download the code
5. go to https://app.netlify.com/drop, sign in or make a free account, drag the folder in
6. it gives you a live link. that's your site, done.
