# sell: find out what your dorm junk is worth

## 1. price it from sold listings, not asking prices

```
here's my item: [name, brand, condition, anything wrong with it]. based on recently SOLD listings (not asking prices) on ebay and facebook marketplace, what's a fair price, and what's the lowest i should accept?
```

check it yourself too: on ebay.com, search the item, then filter by "sold items" in the sidebar. that's what people actually paid.

## 2. write the listing

```
write a facebook marketplace listing for my [item]. title with brand + model + key spec, honest 3 line description that mentions every flaw, price $[X] or best offer, local pickup. keep it casual, not salesy.
```

## 3. lowball replies

```
a buyer offered $[X] on my [item] listed at $[Y]. sold comps for this run about $[Z]. write a short friendly reply countering at $[counter] that mentions what they actually sell for, without being rude.
```

price it right, take decent pics (see [photo](../photo/)), and don't argue with lowballs, just point at comps.
