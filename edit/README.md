# edit: edit video by typing

hyperframes is a free open source tool from heygen. you drop in a clip, type what you want, and it builds the edit.

- repo: https://github.com/heygen-com/hyperframes
- quickstart: https://hyperframes.heygen.com/quickstart

## steps

1. open the repo and grab the free studio app, the readme links downloads for mac, windows and linux
2. drop your clip in
3. type your edit in plain english

## starter prompt

```
make this clip vertical 9:16, add word by word captions, cut the dead air at the start, and put a 2 second title card at the top that says [your text]
```

if you already use an ai coding agent it plugs right in, the repo readme has the setup for that too. some of the fancier models are on a paid plan, the app itself is free.
