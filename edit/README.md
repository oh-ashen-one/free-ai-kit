# edit: edit video by typing

hyperframes is a free open source tool from heygen. you drop in a clip, type what you want, and it builds the edit.

heads up: this one needs a laptop, not just your phone.

- repo: https://github.com/heygen-com/hyperframes
- quickstart: https://hyperframes.heygen.com/quickstart

## how to use this

1. open the repo link on your laptop, scroll the readme, grab the free studio app for mac, windows or linux
2. open the app, drop your clip in
3. paste the box below (fill in the [brackets] first) and let it build

## the starter prompt

```
You are my video editor. Turn my raw clip into a finished short video, not a list of editing tips.

MY INFO:
- My clip: [what's in it, how long]
- Where it's going: [tiktok / reels / shorts]
- Style: [e.g. fast cuts, chill, heavy captions]
- Text and captions: [e.g. word-by-word captions, title card saying "X"]

DO THIS:
1. Cut it vertical 9:16 and trim the dead air at the start.
2. Add word-by-word captions that are easy to read and don't cover the important part.
3. Add a 2-second title card at the top that says [my text].
4. Keep the final edit under [30] seconds.

RULES: Only use what's in my clip, no stock footage unless i ask. Don't change how i look or sound.

OUTPUT: the finished edit plus a list of every change you made.

When done, ask me what to change for version 2.
```

if you already use an ai coding agent it plugs right in, the repo readme has that setup too. some of the fancier models inside are on a paid plan, the app itself is free.
