# offer: sell stuff and handle lowballs

## the job brief i give my ai agent

if you have an ai agent that can run jobs for you:

```
sell my [item]. my floor price is $[X]. write the listing, track buyer replies, and bring me any counteroffer for approval before sending it.
```

## the free version, works in any ai

### price it from sold listings, not asking prices

```
here's my item: [name, condition, anything wrong with it]. based on recently SOLD listings (not asking prices) on ebay and facebook marketplace, what's a fair price and the lowest i should accept?
```

check it yourself too: on ebay.com, search the item, then filter by "sold items" in the sidebar. that's the real number, not what people are hoping to get.

### write the listing

```
write a marketplace listing for my [item]. short title with brand and model, honest 3 line description that mentions every flaw, price $[X] or best offer, local pickup only.
```

### counter the lowball

```
a buyer offered $[X] for my [item] listed at $[Y]. recent sold prices for this are around $[Z]. write a short friendly counteroffer at $[counter] that mentions the sold prices.
```

the trick: never argue. just point at what it actually sells for.
